# Simple Calculator

A lightweight calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Clear and delete actions
- Keyboard support
- Responsive, dark-themed layout

## Run it locally

1. Open `index.html` in your browser, or
2. Serve the folder with a local web server, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — calculator structure
- `styles.css` — styling and layout
- `script.js` — calculator logic and interaction
